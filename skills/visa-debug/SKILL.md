# VISA 仪器诊断

1. 先读已有日志、波形和配置。将仪器型号、探头、量程、单位、采样率和触发设置关联到原始数据。
2. 需要实时操作时，确认实际 VISA 后端、资源和允许的命令。先按[硬件操作权限](../hardware/references/permission-gates.md)核对实际动作。SCPI 查询会发请求，某些查询会清状态。读取屏幕波形可能设置源、读取模式和格式，恢复也会写仪器。记录 `*IDN?` 回读的仪器身份、操作范围及结束状态。
3. 按实际型号的手册核对波形头、字节数、端序、点数、X/Y 缩放和物理单位。证据齐全时交付物理量及时间轴，否则保存原始响应并标为未定标。标明读取的是屏幕窗口还是采集存储，以及参考面、探头设置和支持的判断范围。
4. 有界读取结束后按授权恢复、读回结束状态并关闭会话。交付命令、原始响应、仪器设置和恢复结果。仓内的 [DS1054Z 波形解码](references/waveform-evidence.md)可离线复核已保存的响应。
