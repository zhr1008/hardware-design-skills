# VISA 仪器诊断

1. 先读已有日志、波形和配置。将仪器型号、探头、量程、单位、采样率和触发设置关联到原始数据。
2. 需要实时操作时，确认实际 VISA 后端、资源和允许的命令。核对厂商手册中的命令副作用。使用如 `*IDN?` 的经验证查询时，记录实际仪器身份。
3. 波形二进制读取核对波形头、字节数、端序、缩放和通道。恢复会话前按[硬件操作权限](../hardware/references/permission-gates.md)核对会改变配置、清状态、触发采集、改变输出或启动应用的动作。
4. 有界读取结束后关闭本次会话。按授权验证设备结束状态。交付命令、响应摘要和可复核的原始记录。
