# 系列封装与配对件装配

## 先复用再补齐差异

1. 盘点获准使用的库、对应工程图和模型。区分极数、脚距、孔型、安装方向及机械差异。外观图用于识别款式，标注尺寸与公差依据对应工程图。
2. 同系列先验一个代表款。参数化共用截面、焊盘和装配定位，再以极数、间距和端部变化派生其余规格。批量读回脚号、孔和焊盘坐标、外形跨度及模型。更新库副本时抽取未改版本的关键记录，确认原有几何、链接和模型仍对应。
3. 有相同电气结构、脚号、分件及可连接端的符号时，复制适用图元和引脚数据，更新目标参数和封装关联。保存后核当前模型名、库路径和引脚映射。出现多个封装、重复同号焊盘或显式异号映射时，用器件实际映射表验收。

## 按交付状态定位模型

1. 明确交板端本体、单独插头，还是完全插合总成。总成按配对件型号、插入方向、配合面、插入深度和防呆特征定位。缺装配图或实物时，将推算的插合状态与尺寸标为标称估算。
2. 采用同一长度单位和基准，以 PCB 顶面为 `Z=0`。从基准脚、末端脚及配合面核偏移、旋转和镜像。分别保留板端丝印与插合总成装配投影。最终嵌入后，从保存库提取 STEP，核放置变换与独立模型。
3. 用 CAD 内核比较焊脚截面中心与焊盘位置，必要时做实体相交检查。区分预期接触面和体积干涉。另查插头外壳在 PCB 厚度范围内的 XY 投影及插拔行程。有板框和板厚时按实际板核净空，否则交参考包络及适用边界。

## 重复核验入口

命令只读保存库，使用兼容的 `altium-monkey` 运行环境，已用 `2026.8.11.post1` 验证。默认检查全部符号，可重复传 `--symbol` 缩小范围。 [依赖版本](https://pypi.org/project/altium-monkey/2026.8.11.post1/)

```powershell
python -X utf8 -B scripts/check_pin_pad_links.py example.SchLib example.PcbLib --symbol CONN --require-step
```

- 默认验证恰好一个当前封装关联，以及有编号的引脚和焊盘一一同号。无编号的定位孔可忽略。明确库路径时核对它指向传入库；仅按封装名链接时，原生工程中的库搜索仍须单独核对。
- 使用 `--require-step` 时核关联的内嵌 STEP 能否提取及其文件边界。用 `--step-dir` 另按模型文件名比对独立 STEP 字节。脚本范围止于保存记录、映射及字节，机械坐标和装配按上节继续验收。
- 退出码 `0` 表示所选范围通过，`1` 表示关联、映射或模型证据不符，`2` 表示输入、依赖或库身份不可核。显式映射和共享焊盘应移交器件专项。
- 若使用 `altium-monkey` 生成的独立绘图线在另一解析器中不可见，检查保存轨线的多边形归属。已确认无归属的独立轨线可用 `polygon_index=0xFFFF` 表示，具体接口按实际版本核对。正常多边形轨线保留原归属。复核须以保存库重新导入及实际可见结果为依据。
