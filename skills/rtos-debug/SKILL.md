# RTOS 诊断

收集故障板版、固件、RTOS 及移植层版本、时钟、发生工况和可重现条件。先把现象按时间轴对齐，如任务切换、中断、锁等待、超时、队列积压或看门狗日志。

- 从同一固件的 ELF 和 RTOS 配置解释任务优先级、栈使用、互斥量与事件等待。区分优先级反转、死锁、资源泄露、单纯饥饿与阻塞时间过长。
- 使用厂商插件或 tracing 时先查版本与支持对象。暂停 CPU 或增加 tracing 可能影响时序，标注采样条件并寻找独立复现方式。
- 现场取证按[硬件操作权限](../hardware/references/permission-gates.md)明确板、探针、停止上限和预期结束状态。短时间实验优先使用有界采集，保留原始记录与假设反证。
