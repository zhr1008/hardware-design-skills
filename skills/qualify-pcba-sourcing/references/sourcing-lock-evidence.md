# 资格范围与采购证据合同

每张锁定表对应一个冻结版次和装配变体，按项目原始 BOM 的已装配位号分行。相同选料允许拆成多行记录不同位号或渠道，保留原有用量、MOQ、成本、生命周期、CAD、引脚和替代批准检查。按原始 BOM 与冻结记录保留本表的版次和变体归属。

旧模板 CSV 直接校验时返回原 `sourcing-lock-v1` 结果，自定义扩展列仍作为提示。包含 [v2 模板](../assets/sourcing-lock-v2.csv) 的全部新增表头时自动启用正式证据检查。正式冻结使用 `--formal` 显式启用检查，也适用于表头缺项的文件。正式检查返回 `sourcing-lock-v2`，含实际读取工件的 `sha256` 和 UTC 校验时点 `as_of`。适用的新增证据缺失时加入 `pending` 并返回 `USER_REVIEW`。覆盖不符、证据互相矛盾、过期或数量档不符等冲突进入 `errors` 并返回 `BLOCKED`。两种情况的进程退出码均为 1。

## 制造配置与资格

| 字段 | 记录与校验 |
| --- | --- |
| `qualification_scope` | 填 `required` 或 `not-required`。由项目规格、客户要求、变更影响和已审核的工程判断确定。 |
| `production_configurations` | `required` 时填订单可能使用的全部生产配置 ID。用逗号或分号分隔，建议用分号。配置 ID 对应能在 PCN、供货承诺或来料追溯中核对的制造范围，可涵盖晶圆厂、装配地点、材料或工艺的组合。 |
| `qualified_configurations` | `required` 时填该证据覆盖的配置 ID，必须覆盖当次订单所有允许的配置。按完整 ID 区分大小写，通配符和待核实等占位符不能作为覆盖证据。 |
| `qualification_manufacturer`、`qualification_mpn`、`qualification_package` | `required` 时填写资格报告中本次适用的原厂、完整订购 MPN、准确封装，分别与该行选料完全匹配。即使 `requested_mpn` 与当前 `mpn` 相同仍需匹配。 |
| `qualification_evidence` | 两种范围均需填写可追溯定位。适用时引用原厂资格证据、覆盖资料、配置对应关系及项目接受结论。填 `not-required` 时引用项目已审核的范围依据，并留空覆盖 ID 和三项资格身份。 |

项目规格、报告版次、适用测试与工况、实际批次及 PCN 影响由专业评审核原件。工具核对已录入的范围与选料身份。若现货包含超出资格覆盖的 fab-B，可补齐 fab-B 资格证据，或取得订单和来料均限定在已覆盖 fab-A 的可执行依据后更新表。

## 库存与报价

| 字段 | 记录与校验 |
| --- | --- |
| `supplier`、`supplier_part_number`、`stock_pool` | 用供应商、精确渠道 SKU 和已确认库存池三个 ID 标识共用库存。库存池取供应商实际共用的可分配范围。同一池内所有行的 `order_quantity` 相加，跨报价也合并，并与这一个池的总可用库存比较。 |
| `stock_checked_at`、`stock_quantity`、`evidence_url` | 保存库存快照时间、全池可分配存量和来源定位。同池各行填写相同库存快照时间与存量。库存仍适用原有时效，默认 14 天，可用 `--max-age-days` 调整。 |
| `quote_id`、`quote_evidence` | 填确切报价记录 ID 和报价原件定位。若同一报价文件有多个独立计量的报价项，用含报价行 ID 的组合标识。按供应商、SKU 和报价项合并计费数量，同一个报价项覆盖多个库存池时也按合计量计档。对只在更大采购或其它订单场景才成立的价格，先取得本次可执行报价。 |
| `quote_issued_at`、`quote_valid_until` | 填用于本次判定的报价有效起止时间，使用带时区的 ISO 时间。有效区间含起止两点，与库存快照独立校验。 |
| `quote_min_quantity`、`quote_max_quantity` | 填实际采用价格档的正整数下限与上限，区间含两个端点。原报价明确无上限时填 `unbounded`。同一报价项的时间、价格档及单价必须一致，合计下单数量须落在该档位。 |

核实原件中的币种、批次、替代权限、装配条件和费率适用范围后填入表。费用沿用原表逐行核算，共用费用按订单原件只分配一次。更新同一身份及制造配置的库存和报价后复核采购和订单证据，电气证据继续按其各自覆盖范围复用。

| 合成情景 | 预期 |
| --- | --- |
| 同料号的 U17 实际订单从 fab-A 转 fab-B，项目资格只覆盖 fab-A | `BLOCKED`，指出 fab-B 未覆盖。保留原配置或补入已核实的 fab-B 资格后可通过本项。 |
| 同一供应商 SKU 的共用池只剩 60 件，U17/U18 各订 50 件 | `BLOCKED`。两个确实独立且各有 60 件库存的池可分别通过库存检查。 |
| 同一有效报价的档位为 100–199 件，两行各订 50 件 | 合计 100 件通过数量档。只有一行时数量档不符。有效期届满后的新鲜库存不能延长报价。 |
| 旧表未提供适用制造配置或报价原件，运行正式模式 | `USER_REVIEW` 并列出待补字段，已有冲突仍返回 `BLOCKED`。 |
