# BOM 转物料档案

交付本地物料档案 CSV。以用户提交的 BOM 及本轮明确确认的更改为验收基准。用户本次指定的模板、库、渠道和字段要求优先。查料使用 [component-sourcing](../component-sourcing/SKILL.md) 的商品证据要求，AD 字段按 [AD 字段规则](../component-sourcing/references/ad-field-rules.md) 填写。

默认范围是 BOM 格式转换和物料信息补齐，完成 CSV 读回即达到该任务的交付终点。位号、数量、用途及设计约束取自该 BOM 和用户补充。BOM 未给用途时，可填写器件功能或留空。原理图、网表、PCB、库、焊盘、实物和装配核对均按明确的工程需求另行路由。

成品 CSV、BOM 和 AD 选型表的字段及备注只保留物料业务信息，包括已确认的规格、适用条件、配套件和真实商品链接。缺项在交付字段中留空，清除「待核实」「待核查」「待核对」「待确认」「未录入」「未标注」等占位及纯过程话术。用户操作、同步经过、选型理由、核查缺口和来源冲突在对话或独立说明中交代。

有结构化 CSV 或 XLSX、目标表头和已核对的料号证据时，直接调用 [BOM 批量工具](references/bom-archive-tool.md)。工具一次完成映射、唯一证据补 C 号、保存与读回，不需要为每个 BOM 临时写脚本。输出中的缺证据和歧义交本技能对应步骤解决。

## 1. 确认导入格式和 BOM

- 读取源 BOM 的目标工作表或数据区域和模板的真实表头、列序、编码、分隔符、换行、示例与填写说明。去掉模板中的样例、空行和说明。合并单元格的名称仅在明确的分组范围内补齐。版本以 BOM 或用户确认的信息为准。
- 用户说“按之前格式”且未给新模板时，使用随技能附带的 [物料档案 V1 空表](assets/物料档案_模板V1.csv)，23 列，UTF-8 BOM、CRLF、逗号分隔。默认单位 `PCS`，电子元件大类用 `电子元器件`，小类按模板或器件类别填写。V1 数据示例的状态是 `启用`，作为默认值。已知导入系统或当前模板有更明确要求时按其要求。内部编码、单价、安全库存等无来源且允许留空的字段留空，避免把模板示例的 0 当成真实数据。
- 从 BOM 保留位号、分组、数量及 DNP/变体含义。导入层级 BOM 时，父项在其子树之前，根项通常为 1 级、直属子项为 2 级，保留 BOM 给出的多级结构。数量以源 BOM 和用户补充为准。内部 PCBA 使用已知物料号，无外购渠道料号时该格留空。纯物料档案按模板填写层级和数量。父项或层级缺证时保留已知数据，缺口写入独立的核查说明。

## 2. 逐项确认器件身份和渠道料号

- 默认在国内平台选料，优先国内立创商城，按品类补查国内原厂商城、授权分销或用户指定的国内渠道。品牌优先国产，阻容优先风华。国内未核得合格物料时，在核查说明中列出缺口，交付表中的渠道及料号留空。得捷、Mouser、Newark、element14、国际 LCSC 等海外渠道，须由用户本轮明确指定或授权后才可作为采购候选或写入交付表；原厂数据手册可用于核对规格。
- 对全部采购子件检查渠道料号。BOM 已指定完整型号、品牌或 C 号时，按原身份核对，保留订购后缀。BOM 未指定品牌时，直接从满足其型号或规格、封装等已知约束的产品中选择可靠、价格实惠的品牌，优先国产。通用件可采用符合已给规格的常规商品，把该商品的完整型号及有证据的参数填入对应列。同型号多品牌可以按此原则选用。
- 按 BOM 已给的身份和约束补渠道料号。任务确需为缺型号的阻容选料时，优先已有且适用的商品证据，必要时用当前 `components` 能力查询。用户指定本地库作选料来源时，按阻值或容值、封装以及 BOM 给出的耐压、功率、精度、介质等条件匹配，可按等值单位匹配。明确沿用本机库时可检查 `./component-library`。立创专业版 `.elibz2` 可作为 ZIP 只读检查 `device2.json`。阻容优先风华，再选符合条件的可靠国产品牌。更改 BOM 明确的标称值、封装或最低要求，以用户确认的变更为准。
- 对拟填入的每个立创 C 号，定位对应的**国内立创商品页** `item.szlcsc.com`。按当前工具签名，可用 `szlcsc_get_part` 获取精确身份和国内商品页，再对照页面的型号、品牌、类别、封装及使用的参数。本地库、工具生成文案、搜索摘要、国际 LCSC 和嘉立创装配库可作线索。无法匹配 BOM 明确规格、核实商品身份或查到必要字段时，保留已确认内容，缺项留空。原厂资料与商品页有相关冲突时，在核查说明中记录差异，器件规格按原厂资料判断。选择实惠料时可使用同口径的国内展示价格；用户给出采购数量或供货要求时，才按该条件查库存及对应阶梯报价。

## 3. 映射物料档案与 AD 字段

| 字段 | 填法 |
|---|---|
| 名称、规格 | 名称写器件类别或总成名称，规格写技术参数。阻容规格用国内商品页的阻值或容值，电容微法统一写 `uF`。 |
| 型号、MPN料号 | 型号填原厂完整订购型号或模板要求的内部型号。立创行的「MPN料号」填国内立创 C 号。其他国内渠道按实际订购编号或用户给定的 SKU 填写，记录对应供应商。 |
| 供应商、品牌 | 已核实的立创条目供应商填 `立创商城`，品牌按页面原样，例如 `FH(风华)`。 |
| 封装、位号 | 商品封装按对应国内商品页，例如 `0603`。模板要求源封装时采用 BOM 的封装栏，必要时在备注保留两种名称。位号按源 BOM 保留。 |
| 描述、备注 | 描述按当前 AD 中文规则用半角 `/` 分隔已确认的字段，名称在前。V1 单一描述列可用阻容通用描述，其他器件用有证据的具体描述。备注写适用条件、配套信息及真实链接。 |

- 配套件随主件写在同一行的「备注」。例如电池座配套的可充电电池、板端针座配套的胶壳和压接端子。写明用途、完整型号、已知渠道料号和商品链接。存在按线规等条件选择的档位时，注明适用范围。配套件按源 BOM 或已核实的配接资料填写，用户要求独立采购行时再拆行。
- 淘宝、天猫、京东、1688 等非芯片采购平台的商品链接写在对应物料的「备注」，保留用户提供的完整链接及用于定位款式的 SKU 参数。更新旧档案时补齐有证据的商品链接，并保留原有有效链接及业务备注。

- CSV 的「型号」沿用模板所需的完整订购号或内部型号。AD Comment、描述和商品页字段按 [AD 字段规则](../component-sourcing/references/ad-field-rules.md) 确定格式和列序，成品缺项按本技能留空。
- 用户同时要求完成工程选型或取得 AD 表时，复用本轮已核验数据。字段满足通用导出器的校验时，沿用 [选型导出流程](../component-sourcing/references/ad-selection-export.md)。有需要留空的必填项时，沿用其列序和逐格可复制的表格格式直接生成。单纯补齐已选器件的 C 号或归档字段，交付 CSV 即可。用户只要求附 XLSX 时仅附该格式。

## 4. 保存并读回验收

- 用 CSV 读写器按模板保存，保留字段中的逗号、引号和文本编码。源 BOM、模板和器件库作为输入。更新已有交付时，以用户当前文件为基线，按位号和字段定点合并，保留用户手改的业务信息。Excel 占用导致写入失败时，交付清晰命名的更新副本并说明原文件状态。
- 从保存后的 CSV 核对表头、列数、编码、有效记录、父子顺序和完整型号。用源 BOM 逐项比对各位号、分组数量、DNP、无位号及多级用量。用对应商品页复核新增采购字段。检查成品描述、备注和复制字段中的占位及过程文字已清除，适用条件、配套件和有效链接完整。涉及 HTML 时，核对展示与逐格复制的原文一致。实际导入未执行时，报告文件读回校验的范围。
