# 绝缘配合验证

## 锁定产品要求和隔离边界

按目标市场、使用环境和产品类别确定受控的产品安全标准、采用的国家或地区版本和特殊要求。对每条隔离边界记录两侧电路及可接触件、所需绝缘类别、条件来源、要求的最小距离或电气试验、评审角色与证据定位。

IEC 60664-1 整合版 Ed. 3.1 可作为绝缘配合基础参考，适用范围包括接入低压供电系统且额定电压不超过 `1,000 V AC` 或 `1,500 V DC`、频率不超过 `30 kHz` 的设备，给出超过 `2,000 m` 使用时的指导。附录 G、H 分别定位电气间隙与爬电距离的流程，表 F.10 定位该版次的距离海拔修正。按项目实际引用的版次和产品标准查具体适用条款及数值。公开标准页面足以核对范围、版次与条表定位，数值要求从受控正文或批准的项目规格提取。 [IEC 60664-1:2020+AMD1:2025 CSV，Ed. 3.1，范围及版本变更](https://webstore.iec.ch/en/publication/107319)

| 核验对象 | 取数和审查方法 | 输入和证据 |
| --- | --- | --- |
| 电气间隙 | 寻找两导体之间最短空气路径。按适用标准核查额定冲击电压及稳态、暂态或重复峰值条件，保留采用的电场条件与海拔修正来源。 | 电网额定值及过电压类别、保护装置对瞬态的限制依据、最大使用海拔、装配三维尺寸和公差。 |
| 爬电距离 | 沿适用绝缘表面的最短有效路径核查。依据产品条款确定工作电压口径、污染等级、材料组及对表面形貌的计入规则。 | 隔离边界两侧的最大工作电压与波形、绝缘表面的微环境、实际基材或部件的 CTI/材料组证明、开槽及覆盖工艺。 |
| 固体绝缘 | 核查绝缘结构、最小厚度、材料和老化条件。按产品条款确认耐压、冲击、局部放电与其他适用项目，并区分型式、抽样和例行试验。 | 板叠层、材料批次、绝缘结构图、器件证书及范围、报告中的波形、电压、持续时间、预处理条件和判据。 |

对每条边界记录功能、基本、附加、双重或加强绝缘中的适用类别。查工作电压时分别记录 `DC`、`RMS` 和重复峰值等适用参数及故障工况，查额定冲击耐受时记录取值来源。爬电要求可能受最低电气间隙、产品专用条款或材料组适用性约束，按实际引用的正文核对。项目条件或许可正文缺失时，列出待补的具体输入和条表，暂缓对应验收结论。 [IEC 60664-1:2020+AMD1:2025 CSV，范围、附录 G/H 和表 F.10](https://webstore.iec.ch/en/publication/107319)

## 核对装配后的最短路径

1. 在同一版次的 PCB、装配图和外壳模型中标注隔离两侧。检查铜边、焊盘和焊脚、贯通端子、焊锡突出、板边、槽壁、金属安装件、散热件、屏蔽件和线束。对每条候选路径标出起止部位、介质、测量面、对应版次和最小值，分别从空气与表面候选路径中取最短值。
2. 沿路径核算蚀刻、铣槽、板边定位、装配位置和形变引入的不利变化。槽、筋、阻焊、涂覆和灌封的计入按适用产品条款、几何和工艺资格确认。铜间距 DRC 可用于查平面违例，受限位置用装配后的实体或有效的三维几何证据复核。
3. 同时检查跨界器件及其实际封装装配路径。引脚间空气距离、沿器件外壳的距离和内部固体绝缘证据各有适用工况。将 PCB、组件、壳体等潜在路径放在同一边界下逐条核对。

**原厂报告数据。** TI 在 AMC1400 数据手册列出 DWL 封装外部电气间隙 `≥14.7 mm`、爬电距离 `≥15.7 mm`，并提示 PCB 安装焊盘可能缩短产品上的距离。同一 `1.2/50 µs` 波形下，原厂给出的空气中 `V_IMP` 为 `9.8 kVpk`，用于评价封装，油中型式试验的 `V_IOSM` 为 `12.8 kVpk`，用于评价隔离屏障。应用该证据时分别保留介质、评价对象及电压定义。任何器件认可用于实际产品前还应核对当前可用证书的版次、封装与使用条件。 [TI AMC1400，SBASAI1，2022-07，§6.6，第 6 页，脚注 1、3、4](https://www.ti.com/lit/ds/symlink/amc1400.pdf#page=6)

## 可复算的设计失效与量测判定

本节的虚拟受控要求 `DEMO-INS-001 Rev A §3` 指定边界 B1 为隔离两侧的加强绝缘，工作电压 `400 V DC`，海拔 `≤2,000 m`，污染等级 2，指定表面材料组 IIIa，裸板，无涂覆距离抵扣。该虚拟要求直接提供电气间隙下限 `6.00 mm`、爬电距离下限 `8.00 mm`。数值服务于本算例。实际项目需依据采用的产品标准、适用条件和受控版本确定距离。

| 核查 | 独立手算 | 结果 |
| --- | --- | --- |
| 设计最坏电气间隙 | 最短名义空气路径 `6.40 mm`，不利制造与装配变化合计 `0.30 mm`，保守下界为 `6.10 mm`。 | 比项目下限多 `0.10 mm`。 |
| 设计最坏爬电距离 | PCB 焊盘至对侧焊盘的有效表面路径 `2.00 + 4.20 + 2.00 = 8.20 mm`，其他候选路径在最坏公差下均大于 `8.20 mm`。该最短路径扣除 `0.30 mm` 不利变化后为 `7.90 mm`。 | 比下限少 `0.10 mm`。调整焊盘、铜皮或可计入的几何后再核对全部相关路径。 |
| 假设量测的电气间隙 | `6.14 ± 0.08 mm` 得 `[6.06, 6.22] mm`。 | 该样品通过，保守余量 `0.06 mm`。 |
| 假设量测的爬电距离 | `7.90 ± 0.05 mm` 得 `[7.85, 7.95] mm`。 | 该样品不通过，最坏余量 `−0.15 mm`，区间上端仍缺 `0.05 mm`。 |
| 假设量测的边界样品 | `8.02 ± 0.05 mm` 得 `[7.97, 8.07] mm`。 | 区间跨越下限，结果为不确定。 |

设计公差预算用于评价制造与装配容差下的最小距离。样品的 `U` 对应测量不确定度，记录测量方法、设备校准、重复性、覆盖说明和单位。若项目采用完整区间判定，对包含等号的下限 `L`，`x − U ≥ L` 为通过，`x + U < L` 为不通过，其余为不确定。标准、合同或实验室已明确判定规则时，按对应规则执行。

```powershell
python -X utf8 scripts/engineering_validation.py limit --direction min --value 6.14 --uncertainty 0.08 --limit 6.00 --unit mm
python -X utf8 scripts/engineering_validation.py limit --direction min --value 7.90 --uncertainty 0.05 --limit 8.00 --unit mm
python -X utf8 scripts/engineering_validation.py limit --direction min --value 8.02 --uncertainty 0.05 --limit 8.00 --unit mm
```
