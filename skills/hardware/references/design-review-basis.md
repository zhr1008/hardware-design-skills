# 设计与审查规则

公开版随附 [96 条规则的结构化数据](../assets/review-knowledge/rules.json)，覆盖 9 个设计领域。每条规则记录适用条件、设计动作、审查检查、限制、验证方法与来源页。书目对应整理时采用的版本，换版本或扫描方式后按相应原件核对页码。规则和正文两种入口见 [知识库命令](engineering-knowledge.md#知识库命令)。

| 领域 | 核验范围 | 规则数 |
| --- | --- | ---: |
| PCB与EMC | 回流、参考平面、电源分配、布局及走线 | 22 |
| 模拟与信号调理 | 运放线性区、稳定性、偏置与误差 | 17 |
| 电源与磁件 | 热环路、磁件损耗、稳压和开关应力 | 15 |
| 采样与基准 | 建立时间、采样回冲、滤波和基准误差 | 14 |
| 接口与时钟 | 端接、总线负载、振荡器和起振 | 8 |
| 标准与制造 | 焊盘、装配、孔铜、湿敏与板弯 | 8 |
| 无源器件 | 实际容值、精度、寄生、漏电和温升 | 6 |
| 验证与交付 | 规则检查、模型覆盖和仿真证据 | 3 |
| 热设计与可靠性 | 结温、实际散热条件与额定边界 | 3 |

1. 从实际工程提取电压、电流、温度、频率、负载、接口、标准和版次要求。按[主动工程流程](design-workflow.md)查询规则候选、读取适用条件和来源页，再确定方案或审查判据。
2. 用选用器件的完整型号和原厂资料核对器件边界。项目采用的标准须核对其版次、等级、条款和工况。应用指南与教材用于设计判断，示例值需结合实际工程计算。
3. 把采用的规则对应到位号、网络、布局区域或工程条目。分别记录通过、不通过、待验证及不适用，给出实际证据与待补项。

交付给电路、PCB、固件或综合评审专项时，附规则编号、文档与页码、适用条件、核验对象和结果。缺少实际正文的条目注明证据边界。ERC、DRC、仿真与测量结果按各自执行证据记录。

涉及 SAR ADC 采样建立、参考端或 PDN 目标阻抗时，按 [工程预算](engineering-budgets.md) 计算并留存实际输入、位号或网名、板版次及后续验证条件。

SI、ESD、热、绝缘和可制造性需要跨专项核验时，按 [关键工况的验证交接](engineering-verification.md) 收集实际工况、约束、对象和验收证据。
