# 工程核验与专项交接

按当前问题选读一页。审查记录应能从每条结论回到实际对象与版次、测点或网络、来源条款及版次、工况、项目限值与证据文件。区分原厂实测、设计估算、仿真、现场实测及正式试验。保留限值附近的测量不确定度与适用的判定规则。

| 工程问题 | 深入核验与案例 | 谁执行、交什么 |
| --- | --- | --- |
| SAR ADC 采集、PI／PDN | [工程预算](engineering-budgets.md) | 电路给采集窗、阶跃与电源动态分配，PCB 给实际供电路径和测点，台架复验。 |
| SI、端接、反射、快速边沿 | [信号完整性](si-verification.md) | 电路给接口预算和器件边沿，PCB 查实际回流、走线和支线，台架核接收窗口。 |
| EMC、ESD、发射、保护回路 | [EMC 验证](emc-verification.md) | 电路与 PCB 定保护、布置和回流，台架交 EUT 配置、波形、失效和各工况试验结果。 |
| 结温、瞬态热、功率降额 | [热设计与降额](thermal-verification.md) | 电路给损耗与 SOA，PCB/结构给热路径和公差，台架交实测与模型适用性。 |
| 电气间隙、爬电和固体绝缘 | [绝缘配合](insulation-verification.md) | 电路给受控条件、标准条款与限值，PCB/结构给装配后最短路径，综合评审结合对应试验。 |
| 板厂工艺、装配与生产测试 | [DFM／DFT](dfm-dft-verification.md) | PCB 和制造交同版出件，制造与台架交 CAM 结果、工艺约束与故障覆盖。 |
| AEC 等器件资格与替换 | [器件资格](component-qualification.md) | 器件资格专项逐位号绑定订购型号、配置和原厂资格，变更回流电路、布局和制造。 |

## 固定离线命令

从 `hardware` 技能目录运行 `python -X utf8 scripts/engineering_validation.py <子命令> --help`。公开仓的技能目录是 `skills/hardware`。各主题页有命令和可复算输入。

| 命令 | 结果与边界 |
| --- | --- |
| `rs485-stub` | 依 TI SLLA272D 核 RS-485 短支线，信号窗口按实网另外验证。 |
| `junction` | 由适用的 Ψ_JT、顶面温度和损耗区间得到稳态结温估计区间。 |
| `annular-ring` | 以最坏铜、孔及偏心给圆孔环宽下界，下界不足为 `lower_bound_below_limit`。 |
| `coverage` | 对冻结故障 CSV 计算覆盖率区间，完整保留未完成与漏检项，结果含输入 SHA-256。 |
| `limit` | 已知单项上/下限时比较同单位的完整区间。用于 EMC 读数、绝缘尺寸和器件工况等约定适用的场景。 |

退出码 0、1、2 分别表示模型范围内满足、已证越界、待判或输入无效。环宽下界不足、证据区间跨限及缺项归入 2。上下界含等号时按完整区间判定。用途与输入见 [离线模型](model-checks.md)，项目正式验收沿用批准的决策规则。

原理图把约束和工况交给 PCB，PCB 把版次、位置、叠层和测点交给仿真与台架。发现源头变化时，从对应专项更新受影响工件并重新验收。详见 [跨专项交接](route-matrix.md#跨专项移交与变更回流)。
