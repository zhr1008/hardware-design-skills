# 原理图风格与验收

## 先确定样式基准

- 按用户指定样式和项目模板画。缺省时优先复用电气结构相容的项目符号，其次参考获准访问的同类库件。没有可用样本时，采用目标 EDA 的原生符号和常见电气画法。
- 读代表件的渲染与保存记录，核对网格、引脚节距和连接端、描边、填充、字体及名称和编号的显示。目标器件的原厂 pin 表和封装图决定电气类型、引脚、分件与焊盘映射。
- 同系列可复用[符号和封装的共用部分](../../altium-library/references/series-and-mating.md#先复用再补齐差异)。仅修外观时逐脚守住接线端、编号、方向、分件与映射。

## 按器件类别组织信息

| 类别 | 图形与接线重点 |
| --- | --- |
| 电阻、电容、电感、保险丝 | 使用对应电气符号，保持位号和值易读。两端件可按项目惯例隐藏冗余引脚文字。有极性时保留极性标记。 |
| 二极管、LED、光耦 | 表达阴极、器件类型和光的方向。光耦分别画发光与接收侧，并保留实际接线脚号。 |
| 晶体管与 MOSFET | 表达基极、集电极、发射极或栅极、漏极、源极，按实际结构画方向、体二极管及影响接线的内部保护。 |
| 开关、继电器、变压器 | 开关用触点和拨片，机械联动用虚线。无指定常态的多刀 ON–ON 可参考居中拨片，仍按原厂触点表核脚号与动作。继电器按释放状态画，变压器标明同名端和抽头。 |
| 连接器 | 普通接头用紧凑外框和实际触点编号。USB 等命名接口保留有意义的信号名，同时表达成对触点、屏蔽及不同电源域。 |
| 运放、比较器与复杂 IC | 运放、比较器区分正负输入和供电。复杂 IC 可按功能分组、分件或按封装顺序排脚，逐脚核对原厂 pin 表。 |

## Altium 样式起点

以下为可选参考配置，项目设置优先。保存记录中的 BGR 通道顺序与 SVG 等输出的 RGB 对应。迁移字体时按名称、字号和字重匹配目标库字体表，由目标库分配内部 `FontID`。

| 对象 | 参考外观 | Altium 保存记录 |
| --- | --- | --- |
| 主体电气图形 | 蓝色 `#0000FF`，主体与联动线使用一致笔宽 | `Color=0xFF0000`，常用 `Small`（`LINEWIDTH=1`），细小填充图元可用 `Smallest`（`0`）。 |
| 连接器与复杂 IC 外框 | 暗红描边 `#800000`、浅黄底 `#FFFFB0`，填充压在文字和引脚下方 | `Color=0x000080`、`AreaColor=0xB0FFFF`、`IsSolid=T`，边框 `Smallest`（`0`）。 |
| 引脚 | 常规引脚黑色；保留项目用于极性或电源域的强调色 | 常规 `Pin.Color=0x000000`。附加符号线宽由 `SymbolLineWidth` 控制，引脚长度独立设置。 |
| 位号、值及引脚文字 | 位号和值可选深蓝 `#000080`、Times New Roman 10 pt 常规，引脚文字按目标库 | 位号或 Comment 色 `0x800000`，核实际字体属性、可见性和锚点。 |

例如多刀开关可先用 200 mil 引脚、20 mil 空心触点半径、10 mil 联动短划及 40 mil 短划节距试画，按目标网格、标注间距与实际连通端调整。其他 EDA 沿用相同电气表达，采用目标平台的网格与项目模板。 [Altium 原生符号文档](https://www.altium.com/documentation/altium-designer/components-libraries/creating-schematic-symbol)

## 整页表达与保存态核对

- 按实际信号路径布置输入、保护、处理和输出，常规信号从左向右，供电在上，回流在下。局部关键接线可直接追踪，长距离或跨页连接用端口、网标或总线。按目标 EDA 网格对齐并明确分支连接点。
- 保存后用实际工件渲染，与样本并排检查触点、箭头、色阶、字体、线宽、图层顺序和脚号可读性。符号逐脚核编号、名称、电气类型、连接端、分件和封装关联。Altium 的同号一一映射可运行[引脚与焊盘核对](../../altium-library/references/series-and-mating.md#重复核验入口)。
- 整页用[保存态回读](saved-design-readback.md)核脚网、显式无连接与适用的 ERC。只调整可读性时，按 [schematic-humanizer](../../schematic-humanizer/SKILL.md) 对照整理前后的脚网。只查参数、只核连接或改局部参数时沿用已有样式。
